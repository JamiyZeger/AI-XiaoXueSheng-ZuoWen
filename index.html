AI 接入设置

这里填写你自己使用的大模型服务信息（须兼容 OpenAI 的 chat/completions 接口）。 配置只保存在本机浏览器，不会上传到任何其他地方。常见服务：DeepSeek（api.deepseek.com/v1）、 通义千问（dashscope 兼容模式）、智谱（open.bigmodel.cn/api/paas/v4）、OpenAI（api.openai.com/v1）。
提示：若测试连接报“网络请求失败/CORS”，说明该模型服务不允许网页直连。 解决办法：在项目目录运行 python3 server.py 启动本地服务， 用它给出的地址（如 http://127.0.0.1:8787）打开本页，再勾选上面的“通过本地代理转发”。 API Key 只在本机进程内转发到你配置的模型地址。

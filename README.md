# AI 小学生作文工具（本地网页版）

免登录、免安装的本地网页应用，两大能力：

- **AI 写作文**：给一个题目（或一幅图），选年级、字数，直接生成一篇作文，手写稿展示，可一键去批改
- **AI 批改作文**：输入作文（或看图写话配图）→ 渲染成手写稿 → AI 在稿上画波浪线、改错符号并写评语，支持批改前后对比

## 运行方式

**方式一（最简单）**：直接双击 `index.html` 用浏览器打开（推荐 Chrome / Edge / Safari）。
适合所用模型服务允许浏览器直连的情况（如 DeepSeek、OpenAI 官方接口一般可以）。

**方式二（推荐，解决跨域）**：启动本地小服务（仅依赖 Python3 标准库）：

```bash
cd ai-essay-grader
python3 server.py
# 用它输出的地址打开：http://127.0.0.1:8787/index.html
```

然后在「设置」里勾选**“通过本地代理转发”**，保存即可。
若测试连接时报“网络请求失败 / CORS 跨域”，说明该模型服务不允许网页直连——请改用方式二。
（`server.py` 只监听 127.0.0.1，API Key 仅在本机进程内转发到你配置的模型地址。）

## 首次使用

1. 点右上角「设置」，填写：
   - **API Base URL**：兼容 OpenAI `chat/completions` 的接口地址，如 `https://api.deepseek.com/v1`
   - **API Key**：你的服务密钥（仅存本机浏览器）
   - **对话模型名**：如 `deepseek-chat`；看图写话另配**多模态模型名**（可留空）
2. 点「测试连接」确认可用，保存。
3. 不配置也可以先点首页的「示例批改」看效果（内置示例，不消耗额度）。

## 功能

- **AI 写作文**：输入题目（或上传/选示例图写看图写话）→ 选年级（1~6 年级）和字数（100~800 字左右/不限）→ 生成作文；支持附加写作要求（体裁、风格等）；手写稿展示，可重新生成、复制、一键去批改
- **纯文字批改**：好词好句波浪线/下划线 + 点评；错别字/病句/标点用手绘删除号、增补号、改正号标注并给正确写法
- **看图写话批改**：上传题目图片或选内置示例图，附切题评估（写到的要点 / 漏掉的要点）与 AI 读图内容展示；模型不支持看图时直接提示换模型
- **手写稿**：手写风格字体 + 稿纸背景 + 笔迹扰动；批改前/后切换与滑杆对比
- **整体评价**：分数 + 星级 + 总评 + 建议；一键生成誊清稿
- **历史记录**：本机保存，可导出/导入备份、打印存 PDF

## 已知限制与说明

- **CORS**：部分模型服务不允许浏览器直连（跨域）。遇到“网络请求失败/CORS”时用方式二（`python3 server.py` + 勾选“通过本地代理转发”）即可，无需更换模型服务。
- **API Key 安全**：Key 存于浏览器 localStorage，仅发往你自己配置的模型地址（或本机代理再转发到该地址）；导出备份默认不包含 Key；不建议在公共电脑上保存。
- **字体**：内置「马善政毛笔楷书」（SIL OFL 授权）；加载失败时回退系统楷体。
- **数据**：全部在本机浏览器；清浏览器数据会清掉记录，请适时用「导出备份」。
